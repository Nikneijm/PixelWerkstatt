PixelWerkstattEigenes Essen, Waffen, Deko, Tiere, Blöcke, Skins und Anzeigen für Minecraft auf dem Tablet

PixelWerkstatt ist ein inoffizielles Fan-Werkzeug. Es steht in keiner Verbindung zu Mojang Studios oder Microsoft und wird von ihnen nicht genehmigt oder unterstützt. „Minecraft“ ist eine Marke von Mojang Studios bzw. Microsoft.

Diese Seite sammelt keine Daten. Einstellungen, Zeichnungen und Geräusche bleiben nur im Browser deines Geräts. Ausgeliefert wird die Seite über GitHub Pages; dabei verarbeitet GitHub technisch bedingt die IP-Adresse der Besucher.
