# PixelWerkstatt

Eigene Items, Tiere und Anzeigen für Minecraft Bedrock bauen – direkt im Browser auf dem Tablet.

**Öffnen:** https://nikneijm.github.io/PixelWerkstatt/

## Was man damit machen kann

- **Anzeige:** Herzen und Hunger durch eigene Symbole ersetzen (z. B. Banane, Currywurst) und die Hotbar umfärben.
- **Neue Items:** Banane, Kirschen, Waffe, Schrotflinte mit Patronen.
- **Items umgestalten:** Vorhandene Items wie die Spitzhacke bekommen ein neues Aussehen und funktionieren weiter wie vorher.
- **Tiere:** Vogel, Schmetterling, Elefant (zähmbar und reitbar), Schneeeule und Affe – mit eigenen Farben und selbst aufgenommenen Geräuschen.
- **Pixel-Editor** mit 3D-Vorschau.

Am Ende erstellt die Seite eine `.mcaddon`-Datei, die man mit Minecraft öffnet.

## So kommt das Paket ins Spiel

1. In der PixelWerkstatt unter **Paket** auf **Komplettpaket erstellen** tippen.
2. In der App **Dateien** → **Downloads** die Datei gedrückt halten → **Öffnen mit** → **Minecraft**.
3. In Minecraft die Welt bearbeiten → **Verhaltenspakete** → das Paket aktivieren.

Alle Einstellungen, Zeichnungen und Geräusche bleiben nur im Browser auf dem Gerät gespeichert.
